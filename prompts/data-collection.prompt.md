# Data Collection and Processing

@rfi-assistant 

## Question
What data does GitHub Copilot collect and how is it processed?

## Context
We are completing a data privacy impact assessment (DPIA) for our organization and need detailed information about:
- What specific data is collected from users
- How code snippets and context are processed
- What telemetry data is gathered
- Whether data is used for training models
- Data retention policies
- Options for data deletion

## Required Information
Please provide:
1. Complete list of data collected
2. How each type of data is processed
3. Where data is stored/processed (geographic locations)
4. Whether data is shared with third parties
5. Data retention periods
6. Data deletion procedures
7. Differences between Individual, Business, and Enterprise tiers

## Output Format
Provide a structured response suitable for inclusion in a formal DPIA document, with citations to official sources.

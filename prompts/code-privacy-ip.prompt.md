# Code Privacy and Intellectual Property Protection

@rfi-assistant

## Question
How does GitHub Copilot handle code privacy and intellectual property?

## Context
We develop proprietary software and need assurance that our code and intellectual property are protected when using GitHub Copilot. Our concerns include:
- Whether our code is used to train AI models
- How code confidentiality is maintained
- Risk of code leakage to competitors
- Intellectual property ownership

## Required Information
Please provide:
1. Is customer code used for training models?
   - Differences between Individual, Business, and Enterprise tiers
2. How is code kept confidential?
3. What measures prevent code from being shown to other users?
4. Who owns code generated by GitHub Copilot?
5. What happens to code snippets sent for suggestions?
6. Content exclusion capabilities for sensitive code
7. Can we prevent certain repositories from being processed?
8. What indemnification is provided for IP issues?
9. How is copyright and licensing handled?

## Output Format
Provide a detailed response addressing each concern, suitable for review by our legal and security teams, with citations to official terms and policies.

# GDPR Compliance Information

@rfi-assistant

## Question
How does GitHub Copilot comply with GDPR requirements?

## Context
As a European organization, we must ensure that all tools we use comply with GDPR regulations. We need comprehensive information about:
- Data processing agreements
- Data subject rights
- Data residency options
- Cross-border data transfers
- Privacy by design measures

## Required Information
Please provide:
1. GitHub's role as data processor/controller
2. Data Processing Agreement (DPA) availability
3. How to exercise GDPR rights:
   - Right to access
   - Right to rectification
   - Right to erasure (right to be forgotten)
   - Right to data portability
   - Right to object
4. Data residency and where data is processed
5. Standard Contractual Clauses (SCCs) or other transfer mechanisms
6. EU Data Protection compliance measures
7. Contact information for data protection officer

## Output Format
Provide a comprehensive GDPR compliance overview suitable for our legal team's review, with citations to official privacy policies and documentation.

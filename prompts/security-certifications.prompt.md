# Security Certifications and Compliance

@rfi-assistant

## Question
What security certifications and compliance standards does GitHub Copilot have?

## Context
Our procurement department requires documentation of security certifications before approving new tools. We need to verify compliance with:
- SOC 2 Type II
- ISO 27001
- ISO 27018
- Other relevant security standards

## Required Information
Please provide:
1. Current security certifications held
2. Compliance standards met (GDPR, CCPA, etc.)
3. How to obtain audit reports (SOC 2, etc.)
4. Certification renewal and maintenance processes
5. Links to official certification documentation
6. Any industry-specific compliance (HIPAA, FedRAMP, etc.)

## Output Format
Provide a structured list of certifications with:
- Certification name
- Certification body
- Date of most recent certification
- Link to official documentation
- How to request audit reports
